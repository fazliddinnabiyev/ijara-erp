# KvartiraERP v3.0

Shaxsiy kvartira ijarasi uchun Next.js ilovasi.

## Ishga tushirish

```bash
npm install
npm run dev
```

## Vercel

GitHub repository ildizida `package.json`, `app/`, `lib/` va `prisma/` bo‘lishi kerak. Vercel Project Settings → Root Directory maydoni bo‘sh (repository root) bo‘lishi kerak.

## Eslatma

Hozirgi versiyada yozuvlar brauzerning `localStorage` xotirasida saqlanadi. Bu bitta brauzer/qurilma uchun prototip; real server bazasi va ko‘p qurilmada sinxronlash uchun alohida ma’lumotlar bazasini sozlash kerak.
