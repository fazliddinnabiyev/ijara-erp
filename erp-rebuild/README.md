# KvartiraERP Premium

Next.js App Router + React + Tailwind CSS project for a single-owner apartment rental business.

## Run locally

1. Install Node.js 20.9 or newer.
2. Run `npm install`.
3. Run `npm run dev` for development or `npm run build` for production build.

## GitHub / Vercel

Upload the CONTENTS of this project folder to the repository root (not an extra nested `ijara-erp-main` folder). `package.json` and `app/` must be visible at the repository root. Then commit and let Vercel redeploy.

The dashboard is styled to follow the supplied KvartiraERP reference. Data entry currently uses browser localStorage, so it is stored per browser/device rather than in a shared database.
